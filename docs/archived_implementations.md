# Original predictive implementations

The JSON manifest lists original scripts, checksums, and imports. The compact
runner pins the installed minimal environment. Original neural scripts also
use torch 2.4.1+cpu in the local audit environment. The foundation-model role
script records TabPFN 8.1.0 and Chronos 2.2.2, pretrained weights and history
parameters; these optional packages and weight downloads are outside the
minimal demo environment. The original scripts expect their archived feature
tables and chronological training history. Restricted inputs are not bundled.
Seed counts, epochs, architectures, and calibration settings are preserved in
source. Equal training compute was not recorded across model families; the
manuscript comparison is configuration-specific rather than a compute-matched
benchmark. The released deterministic entry points were tested independently.
